# Diwali Utsav Planner

A beginner-friendly Flask website with an interactive rangoli planner, design ideas, shopping list, decoration tips, and budget calculator.

## Run in GitHub Codespaces

```bash
python -m pip install -r requirements.txt
python app.py
```

Open the **Ports** tab and open port **5000** in your browser.
